GLASSY LAUNCHER 1.1.16 (code 216) - Home problem: report build
================================================================

Kya badla
- Test icon (LAUNCHER) wapas hata diya. Ab ek hi icon hai, jaisa pehle tha.
- Ab app khud likhta hai ki Home ke saath kya hua: kab resume hua, kab stop hua,
  process kitna purana tha, Android ne memory maangi ya nahi, crash hua ya nahi.
- Report mein phone ka navigation mode (gestures ya buttons) aur ROM bhi aata hai.

Report kaise nikalein (problem hone ke baad, jab phone ka stock launcher khula ho)
1. Glassy ka icon kholen (ye Settings kholta hai).
2. "Home app log" wali row par tap karein. "Home report copied" likha aayega.
3. Chat mein paste karke bhej dein.
(Agar Glassy Home screen par ho: "Set as default home app" chip par long-press bhi report copy karta hai.)

Test ke steps
1. Build karke purani app ke upar install karein. Package: com.oklabs.oneui9launcher
2. Glassy ko Home app banayein.
3. Phone restart karein. Chrome kholen. Home dabayein.
4. Jab stock launcher khule, upar wala report nikalein aur bhejein.
